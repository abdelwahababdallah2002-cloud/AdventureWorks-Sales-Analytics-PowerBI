# 🚴 AdventureWorks Sales Analytics | Power BI

## 📊 Project Overview

**AdventureWorks Sales Analytics** is an interactive **Power BI Business Intelligence project** built to analyze sales performance, customer behavior, product performance, returns, and geographic trends.

The dashboard transforms AdventureWorks business data into interactive reports and KPIs that help users understand revenue, orders, profitability, returns, customers, and product performance.

---

## 🎯 Project Objectives

The main objectives of this project are to:

* Analyze overall sales performance.
* Track revenue and order trends.
* Monitor monthly performance against targets.
* Analyze product and category performance.
* Understand customer purchasing behavior.
* Identify top customers.
* Analyze customer income and occupation.
* Track product returns.
* Explore geographic sales performance.
* Provide an interactive and user-friendly BI dashboard.

## 🗂️ Data Model

The project uses a structured AdventureWorks data model containing sales-related and lookup tables.

Main tables include:

* **Sales Data**
* **Product Lookup**
* **Product Categories Lookup**
* **Product Subcategories Lookup**
* **Customer Lookup**
* **Territory Lookup**
* **Calendar Lookup**
* **Returns Data**

The model also includes dedicated measures and supporting tables for analytical calculations and dynamic metric selection.

## 📑 Dashboard Pages

### 🏠 Home Page

The landing page provides navigation to the main analytical sections of the report.

---

### 📈 Main View

The main dashboard provides an overview of business performance through:

* Revenue trends
* Monthly revenue
* Monthly orders
* Monthly returns
* Orders by category
* Most ordered product type
* Most returned product type
* Interactive filters

This page acts as the main executive overview of the business.

---

### 🌍 Maps

The Maps page provides a geographic view of business performance, allowing users to explore sales-related information across territories and locations.

---

### 👥 Customer Analysis

The Customer page focuses on customer behavior and segmentation.

It includes:

* Orders by income
* Orders by occupation
* Top 100 customers
* Top customer by revenue
* Customer order analysis
* Revenue and order KPIs
* Interactive customer filters

---

### 📦 Product Analysis

The Product page focuses on product performance and target tracking.

It includes:

* Monthly orders vs. target
* Monthly profit vs. target
* Monthly revenue vs. target
* Profit trends
* Return trends
* Product selection
* Interactive product filters

A dedicated tooltip page provides additional category-level information, including weekly order trends, when users interact with the relevant visualizations.
